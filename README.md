# משמרת לילה במחלקה הפנימית: חדר בריחה אנדוקריני

*Endocrine Escape Room: a self-contained, browser-based escape room for high-school health-science classes (Hebrew, RTL).*

תלמידים מגלמים מתמחים בתורנות לילה. הם עוברים 8 תחנות בבית חולים, מאבחנים כל חולה, מזהים את ההורמון שמאחורי המחלה, בוחרים טיפול, ואוספים אות מכל תחנה. האותות מרכיבים מילת קוד שפותחת את דלת היציאה. בסוף כל תלמיד או זוג כותב רפלקציה ומקבל דוח PDF להגשה.

- ⏱️ שיעור כפול (עד כשעה): משחק של 30–45 דקות ואחריו רפלקציה.
- 📱 מותאם לטלפון: כל תלמיד או זוג על מכשיר אחד.
- 🏁 טיימר ברקע, עם קנסות על טעויות ורמזים, להשוואה בכיתה.
- 🌐 בלי שרת ובלי הרשמה. קבצים סטטיים בלבד.

## הרצה

**אפשרות 1: GitHub Pages (מומלץ לכיתה).** בהגדרות הריפו: Settings ← Pages ← Source: `main` / root. שולחים לתלמידים את הקישור.

**אפשרות 2: מקומית.** פותחים את `index.html` בדפדפן. הכול עובד גם בלי אינטרנט (חוץ מגופן Heebo, שיש לו ברירת מחדל).

## למורה

- **דירוג:** בסוף כל תלמיד לוחץ "העתקת קוד תוצאה" ושולח לכם את הקוד (ENDO-…). הדביקו אותם ב־`teacher.html` ותקבלו טבלת דירוג.
- **מפתח תשובות:** ב־`teacher.html`, נוצר אוטומטית מקובץ התוכן.
- **דוח לתלמידים:** מסך הדוח נשמר כ־PDF דרך הדפסה, או מורד כטקסט.
- **התקדמות נשמרת** בדפדפן (localStorage), כך שרענון לא מאפס. "התחלה מחדש" בתחתית המפה מאפס.
- **ניקוד:** זמן סופי = זמן משחק + קנסות. טעות 15 שניות, רמז 20/40/60 שניות.

## עריכת תוכן

כל התוכן ב־`js/content.js`. אפשר להחליף חולים, שאלות, תשובות, שמות הדמויות ומילת הקוד בלי לגעת בקוד המנוע.

סוגי שלבים (`type`):

| סוג | שדות עיקריים |
|---|---|
| `choice` | `options`, `answer` (אינדקס) |
| `multi` | `options`, `answer` (מערך אינדקסים) |
| `text` | `fields: [{label, accept: [...]}]`. ההשוואה מתעלמת מרווחים, ניקוד וסימני פיסוק |
| `match` | `pairs: [{left, right}]`, `choices` |
| `sequence` | `items` (בסדר הנכון, המנוע מערבב) |
| `body` | `multi`, `answer: ['face','hands',...]` (אזורים: face, neck, chest, abdomen, hands, legs) |

לכל שלב אפשר להוסיף `hints` (עד 3), `explain`, ו־`before: {story, images}` להצגת מידע חדש לפני השלב. הוסיפו תחנה חדשה כאובייקט נוסף ב־`stations`, ותנו לה `letter` שמרכיבה את `exit.word`.
